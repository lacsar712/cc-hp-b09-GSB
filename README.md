# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

另有**处方投料汇总卡**：炮制员为一张处方卡挂多味饮片和目标克重，专页汇总每味已成功写入的次数与最近结论；可签发处方快照，冻结签发当时各味的次数与结论，之后的新写入只改现场卡、不动快照。质检员能看卡与快照，但不能建卡、不能写入、不能签发。

## 页面

- 顶栏挂「首页」与「处方汇总」链接。
- 首页（`#/`）：炮制记录，一整张卡，不是专页。
- 处方汇总专页（`#/rx`）：建卡区、现场汇总（每味目标克重 / 已成功写入次数 / 最近结论 / 写一笔 / 签发快照）、已签发快照链接。
- 快照页（`#/rx/snap/{id}`）：冻结视图，标注签发人与签发时间，后续写入不改变本页。

## 处方卡接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/api/rx/cards` | 炮制员：建卡（处方名 + 多味饮片目标克重） |
| GET | `/api/rx/cards` | 登录：所有卡现场汇总 |
| GET | `/api/rx/cards/{id}` | 登录：单卡现场汇总 |
| POST | `/api/rx/cards/{id}/writes` | 炮制员：给卡内某味写一笔 |
| POST | `/api/rx/cards/{id}/snapshots` | 炮制员：签发快照（冻结当时次数与结论） |
| GET | `/api/rx/snapshots/{id}` | 登录：查看快照 |

## 验收

炮制记录（首页）：

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。

处方投料汇总卡（处方汇总专页）：

4. processor 建卡挂甘草（及其他味）与目标克重；给甘草写一笔，现场「已成功写入次数」为 1，最近结论为放行。
5. 签发处方快照后，再给甘草写一笔：现场次数变 2；打开刚签发的快照，甘草次数仍为 1（快照不动）。
6. checker 能打开现场卡与快照，但看不到建卡区、写一笔、签发快照按钮（直接调接口返回 403）。
